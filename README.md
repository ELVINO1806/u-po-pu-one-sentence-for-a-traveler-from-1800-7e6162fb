Competition: **One Sentence for a Traveler from 1800**
Slug: `u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb`

This entry explains the internet to a person from 1800 in a single sentence, using only imagery that would have made sense in their era: post offices, libraries, desks, roads, and letters. The sentence builds one shared picture — every library and post office on Earth gathered at a single desk — and lets the speed of the reply do the explaining, so the wonder lands without any modern vocabulary.

The constraint is what makes the sentence work. A traveler from 1800 has no word for a network, a server, or a search engine, but they know what it means to wait weeks for a letter and to walk to a library for a single fact. By keeping every image inside that world — one desk, copper roads instead of wires, a letter answered before the ink dries — the entry turns an abstract modern system into something the traveler can picture standing in front of, and the impossibility of the speed becomes the point rather than a detail to explain away.

## How it works

`main.py` writes the entry sentence to `/output/entry.txt`.

```sh
python3 main.py
```
